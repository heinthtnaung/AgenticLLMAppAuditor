# --- Phase 1: Environment & LLM surface extractor ---
# Python 3.10+ required (uses modern type hints like list[Path]).
#
# The auditor analyses Python with the standard library's own `ast` module.
# There is no JavaScript parser in the standard library, so tree-sitter is the
# one exception to the stdlib-first rule. It parses locally, with no network
# access, so the offline boundary is unaffected.
#
# Versions are pinned exactly, not with >=: a grammar update renames node
# types, which would silently change surfaces.json -- the artifact Phase 4's
# precision and recall are computed from.
tree-sitter==0.26.0
tree-sitter-javascript==0.25.0
tree-sitter-typescript==0.23.2

# Ollama is installed as a SERVER, not from here. src/model_client.py talks to
# it over urllib:
#   ollama pull qwen2.5-coder:7b-instruct

# --- Phase 3: the agentic audit workflow ---
# LangGraph is a deliberate exception to the stdlib-first rule, and not because
# a bounded loop needs a framework -- that is about sixty lines of plain Python.
# It is here because the thesis argues an agentic LLM app should be audited by
# one, so the auditor is built the way the apps it audits are built.
#
# It brings a large tree with it, including langsmith, whose tracing would send
# data off the machine. src/checks/workflow.py disables that explicitly rather
# than relying on it being off by default; tests/parsing/test_offline.py holds
# the guarantee.
langgraph==1.2.11

# Testing
pytest>=8.0.0

# --- Phase 5: exporting the reports ---
# The THIRD exception to the stdlib-first rule, after tree-sitter and langgraph
# above. A PDF writer is not something the standard library has, and this one is
# chosen over weasyprint because it is pure Python: an examiner can install it
# without cairo, pango or gdk-pixbuf, which is the difference between a report
# that builds on their machine and one that does not.
#
# It needs a Unicode TTF, which is NOT committed -- both reports print an em
# dash, and fpdf2's built-in fonts are Latin-1 only. src/export_reports.py looks
# for DejaVu on the machine and skips the PDF when there is none, exactly as a
# missing Syft yields no bill of materials. The HTML never depends on it.
fpdf2==2.8.8

# --- Phase 6: grounding the remediation advice (RAG) ---
# The FOURTH exception to the stdlib-first rule, and the only one that cannot
# argue the standard library was unable to do the job. Exact cosine search over
# a few thousand vectors is a short loop, and this project would normally write
# it. ChromaDB is here because it was asked for by name, so the honest record is
# that this is a choice, not a necessity.
#
# What it costs, measured on 2026-09-04: about sixty packages, including
# onnxruntime, five opentelemetry packages, huggingface_hub, kubernetes, grpcio
# and a web server. None of it is used here -- the store is opened as a local
# file, never as a service.
#
# Two of its defaults would break this project's offline guarantee, and both are
# closed in src/retrieval/store.py with a test on each: its default embedding
# function fetches a model over the network the first time it embeds text (so a
# refusing function is always attached and the store accepts vectors only, which
# src/model_client.py computes against local Ollama), and its client reports
# usage telemetry unless told not to. Measured with every socket refused:
# importing, opening, indexing and querying attempt no connection at all.
chromadb==1.5.9
