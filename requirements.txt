# --- Phase 1: Environment & LLM surface extractor ---
# Python 3.10+ required (uses modern type hints like list[Path]).
#
# The auditor analyses Python with the standard library's own `ast` module.
# There is no JavaScript parser in the standard library, so tree-sitter is the
# one exception to the stdlib-first rule. It parses locally, with no network
# access, so the offline boundary is unaffected.
#
# Versions are pinned exactly, not with >=: a grammar update renames node
# types, which would silently change surfaces.json -- the artifact Phase 4's
# precision and recall are computed from.
tree-sitter==0.26.0
tree-sitter-javascript==0.25.0
tree-sitter-typescript==0.23.2

# --- Phase 3: the agentic audit workflow ---
# LangGraph is a deliberate exception to the stdlib-first rule, and not because
# a bounded loop needs a framework -- that is about sixty lines of plain Python.
# It is here because the thesis argues an agentic LLM app should be audited by
# one, so the auditor is built the way the apps it audits are built.
#
# It brings a large tree with it, including langsmith, whose tracing would send
# data off the machine. src/checks/workflow.py disables that explicitly rather
# than relying on it being off by default; tests/parsing/test_offline.py holds
# the guarantee.
langgraph==1.2.11
